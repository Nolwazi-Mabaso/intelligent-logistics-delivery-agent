# Intelligent Logistics Delivery Assignment Agent

## Overview
This project implements an AI rational agent designed to optimise delivery assignment within a logistics environment. The system intelligently allocates delivery tasks based on operational constraints such as workload, distance, and delivery priority.

The project demonstrates principles of intelligent agents, optimisation, and decision-making systems.

---

## Problem Statement
Logistics operations require efficient delivery assignment to minimise inefficiencies and improve operational performance. Manual allocation can lead to delays, workload imbalance, and inefficient routing.

This project addresses the problem by developing an intelligent agent capable of making automated delivery assignment decisions.
